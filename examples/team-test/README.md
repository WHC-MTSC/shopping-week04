# 팀원 테스트용 CSV

두 파일 모두 `hour,count` 열과 **연속된 168시간의 데이터 행**을 포함합니다. 헤더를 합치면 169행입니다. 2011년 영국 소매 자료를 이용한 실습용 이력입니다.

| 파일 | 예측 시작 시각 (원본 현지 시각) | 기본 모델 예측 | 정답 입력 실습값 |
| --- | --- | --- | --- |
| [normal.csv](normal.csv) | `2011-09-27T08:00:00` | 보통 | 실제 판매전표 1건 |
| [busy.csv](busy.csv) | `2011-09-27T10:00:00` | 혼잡 | 실제 판매전표 16건 |

## 사용 방법

1. 파일 페이지에서 **Download raw file**로 CSV를 내려받습니다.
2. 실행 중인 Hourahead 화면의 **CSV 파일 불러오기**에서 파일을 선택합니다.
3. 데이터 출처는 **실습·테스트 데이터**로 유지합니다.
4. 예측 시각이 자동 설정되지 않는 기존 화면에서는 위 표의 시각을 직접 입력합니다. 날짜만 다른 시각으로 바꾸지 마세요.
5. **예측 실행** 후 위 실습값으로 정답을 저장하고 같은 예측 ID의 기록을 확인합니다.

기본 모델 `77f4c9c1af34`로 보통·혼잡 예측과 저장 동작을 확인했습니다. 모델을 교체했다면 예측 결과는 달라질 수 있습니다. 이 파일은 과거 데이터 재생 실습이므로 실제 운영 자료로 표시하거나 학습에 섞지 마세요.
