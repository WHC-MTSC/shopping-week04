## 독립 교차 리뷰

백엔드 작성자와 UI 작성자가 서로의 변경을 검토하고, 별도 리뷰어가 문서·권한·CI·비밀정보 포함 여부를 확인했습니다. 아래 문제를 수정했습니다.

- 동일한 예측을 다시 실행하는 동안 정답 POST 응답이 무시되는 경합: 같은 예측 ID의 선택 버전을 유지하고, GET/POST 응답 순서 두 가지의 회귀 테스트를 추가했습니다.
- S3 `412 PreconditionFailed`를 무조건 전송 성공으로 처리하는 문제: 기존 객체의 길이와 JSON bytes를 읽어 비교합니다. 내용 불일치나 읽기 실패는 대기 상태로 남깁니다. 읽기는 같은 로그 접두사로 제한합니다.
- S3 모드 설정만으로 연결 성공처럼 보이는 안내: '실제 S3 전송 모드'로 수정했습니다.

수정 후 검토 범위에서 추가로 확정한 차단 결함은 없습니다.

## 검증 한계

실제 AWS 리소스를 만들거나 실제 S3·CloudWatch 전송을 검증하지 않았습니다. CloudWatch 직접 수집은 구현하지 않았고 `/log-console`은 CloudWatch 스타일의 로컬 로그 화면입니다. 로컬 모사 성공은 AWS 권한 검증을 의미하지 않습니다.

브라우저 접근 허용 후에도 캡처 도구의 저장된 권한/관리 정책 차단이 계속되어 화면 캡처와 실제 브라우저 상호작용 검증은 완료하지 못했습니다. 스크린샷을 첨부한 것으로 간주하지 않습니다.

앱은 인증이 없는 로컬 개발용입니다. 외부 공개 전 예측·정답 작성과 기록 조회에 접근 제어가 필요합니다.
