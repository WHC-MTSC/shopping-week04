# 쇼핑 주문처리 작업량 예측

이 저장소의 `data/model-input.csv`는 2주차 `shopping-week02/result/model-input.csv`의 복사본입니다. 원본은 UCI Machine Learning Repository의 [Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)이며, 한 행은 연속된 한 시간 구간입니다. 목표 `positive_sales_invoice_count`는 해당 시간의 양수 판매전표 건수입니다.

4주차 모델 학습과 평가는 `train.py` 및 `artifacts/`에 정리합니다.
